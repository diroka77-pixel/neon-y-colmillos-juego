## Generación 3D prevista

Se ha elegido Meshy como primera opción para el modelo de Diroka. Sus condiciones actuales indican que las salidas del plan gratuito se ofrecen al usuario bajo licencia CC BY 4.0, con atribución a Meshy. Los planes de pago conceden propiedad sobre la salida, siempre que las imágenes de entrada no infrinjan derechos ajenos.

- Condiciones: https://www.meshy.ai/terms-of-use
- Explicación de uso comercial: https://help.meshy.ai/en/articles/9992001-can-i-use-meshy-assets-commercially-license-copyright-explained

Si se incorpora al proyecto un modelo generado con el plan gratuito, aparecerá aquí con la atribución: `Model created with Meshy – CC BY 4.0 License`.

Tripo no se utilizará con el plan gratuito porque sus condiciones actuales no conceden uso comercial de las salidas gratuitas. Solo podrá usarse con un plan de pago autorizado expresamente por el director del proyecto.

- Información de Tripo: https://www.tripo3d.ai/help/privacy-policy/how-to-use-tripo-models-commercially
